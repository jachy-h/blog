# v1.0.0 全站视觉改版计划

- 状态：已批准并实施（执行记录见 `docs/v1.0.0-progress.md`）
- 范围：全站页面
- 方向：技术编辑感（Technical Editorial）
- 主题策略：保留 PaperMod 作为底层，覆盖布局与样式；不修改主题 submodule
- 明暗主题：保留自动跟随系统 + 手动切换
- 发布策略：只做本地构建与验证，不提交、不推送、不触发 Pages 部署

---

## 1. 目标

把现在的「PaperMod 加几块自定义样式」整理成一套完整、可维护的个人站点设计系统：

1. 首页从「信息堆叠」变成有明确第一屏、有节奏的编辑式版面。
2. 文章页从「窄栏 + 主题默认目录」变成适合长文阅读的两栏结构：目录、正文、脚注、上下篇各自有位置。
3. 列表、归档、分类、项目、搜索、404 统一到同一套网格、字号、色板与交互。
4. 去掉模板感最重的部分：emoji 项目图标、随机分类色相、默认卡片、默认页脚、默认移动端菜单。
5. 保留现有内容、URL、front matter、搜索、RSS、GoatCounter、Cloudflare 统计与 CI 构建方式。

非目标：

- 不重写文章内容，不新增未经证实的数据、评价或人物信息。
- 不改文章目录结构与永久链接，不引入评论、会员、 newsletter 等新功能。
- 不更换 Hugo，不引入前端框架，不做需要常驻服务的方案。
- 不修改 `themes/PaperMod` 内部文件。

## 2. 设计系统

### 2.1 网格与版心

| 项 | 值 |
|---|---|
| 页面 shell | `max-width: 1240px`，左右留白 `clamp(20px, 5vw, 80px)` |
| 栅格 | 12 列，列间距 24px；1024 以下 8 列；768 以下单列 |
| 文章正文 | `max-width: 34em`（约 680–720px），目录占左侧 3 列 |
| 区块间距 | `clamp(72px, 11vh, 132px)`，桌面端每块接近一屏 |
| 圆角 | 0（按钮、输入框、图片框均为直角；仅标签用胶囊） |
| 边框 | 1px 发丝线，作为主要分隔手段，不用大面积阴影 |

### 2.2 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 中文正文 / 标题 | `"PingFang SC", "HarmonyOS Sans SC", "Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif` | 不加载中文字体，避免几 MB 的字体请求 |
| 拉丁展示 / 数字 | Space Grotesk（自托管 woff2，仅 Latin 子集） | 用于 wordmark、英文标签、超大数字；`font-display: swap` |
| 索引 / 日期 / 元信息 | `ui-monospace, "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace` | 12–13px，字距 `.06em` |
| 代码 | 同上 | 14px / 1.7，保留 Chroma 语法高亮 |

字号阶梯：

- 首页 h1：`clamp(56px, 7.6vw, 104px)`，行高 1.02，字距 `-0.02em`
- 页面 h1：`clamp(36px, 4.6vw, 56px)`，行高 1.1
- 区块 h2：`clamp(28px, 3vw, 40px)`
- 条目标题：22–32px
- 正文：17px / 1.85
- 辅助文字：14px / 1.7
- 索引标签：12px，大写或等宽

### 2.3 色彩

用「纸 / 墨 / 朱砂」三色体系替代当前的深灰 + 墨绿：

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--paper` | `#f4f1ea` | `#0d0e0f` | 页面底色 |
| `--surface` | `#ebe6da` | `#15171a` | 卡片、代码、索引面板 |
| `--ink` | `#17171a` | `#ecebe4` | 正文、标题 |
| `--muted` | `#625f56` | `#918e86` | 次要文字、日期 |
| `--line` | `#d6d0c2` | `#282b2f` | 发丝线、边框 |
| `--accent` | `#b83a27` | `#ff6b4d` | 链接下划线、编号、当前状态、强调 |
| `--accent-ink` | `#fffaf6` | `#140b09` | 强调色上的文字 |

取舍说明：

- 朱砂只做小面积信号色，不铺背景，不用于大面积文字。
- 分类不再按名称生成随机色相；分类的识别交给编号、名称与计数，避免全站出现第二套颜色系统。
- 正文对比度目标 ≥ 7:1，次要文字 ≥ 4.5:1，链接颜色在明暗两套主题下分别校验。
- 禁用紫色 / 薰衣草色。

### 2.4 视觉母题

- 发丝线分隔 + 等宽编号：`01 / 项目`、`2026.11.13`、`13 篇`。
- 首页第一屏左侧是大字，右侧是「INDEX」信息板：文章数、项目数、最近更新、订阅入口；所有数字由 Hugo 在构建时计算，不写死、不编造。
- 细网格只出现在首页 hero 背景，透明度低于 4%，作为技术编辑感的底纹，不影响阅读。
- 项目不再使用 emoji 图标，改为等宽序号（`01`–`04`）；没有真实 logo 的项目不画假 logo。
- 图片一律贴边、直角、1px 边框；不加说明文字或 caption。
- 不做倾斜、错位、重叠、装饰性噪点、渐变光斑。

### 2.5 动效

| 场景 | 行为 |
|---|---|
| 首屏进入 | 一次性的行级上移 + 淡入，600ms，`cubic-bezier(.22,1,.36,1)`，逐行 70ms |
| 链接 / 导航 | 下划线从左向右绘制，180–220ms |
| 项目 / 文章行 | 背景轻微着色，箭头右移 4px，行本身不上浮 |
| 按钮 | hover 下沉 1px 的视觉反馈，按下回到 1px，颜色加深 |
| 卡片 / 图片 | 图片在框内放大 1.02；不倾斜 |
| 收尾区 | 唯一一个「dealt moment」：进入视口时关键词依次点亮一次，之后静止 |
| 滚动 | 不做滚动视差、不做逐块淡入、不做滚动劫持；目录只做当前项状态切换 |
| 减弱动效 | `prefers-reduced-motion` 下全部静止，不保留隐藏内容 |

## 3. 页面设计

### 3.1 全局外壳

- 顶部：72px 导航，发丝线下边；左侧 `JACHY` wordmark + `开发实践` 小字；右侧菜单、主题切换、搜索。
- 移动端：wordmark + 菜单按钮；打开后是全屏面板（导航、主题切换、RSS、GitHub、Telegram），支持 Esc 关闭、焦点返回、`aria-expanded`。
- 无 JS 时菜单直接展开，不出现无法打开的死按钮。
- 页脚：三栏（站点说明 / 索引 / 订阅），底部一行版权与 `Hugo + PaperMod` 署名。
- 保留 skip link；焦点环 2px 朱砂，offset 3px；所有可点击目标 ≥ 44px。

### 3.2 首页

1. **Hero（第一屏）**
   - 左侧：`JACHY / 开发实践与个人工具` → 大字「想到了 / 就去试试」→ 两句介绍 → 主按钮「了解我」+ 次按钮「全部文章」。
   - 右侧：INDEX 信息板（文章数、项目数、最近更新时间、RSS）。
   - 第一屏内必须出现主操作；背景细网格只在 hero 内。
2. **项目（01）**
   - 标题「把想法做成工具」；4 行项目索引：编号、名称、一句话、标签、箭头。
   - 整行可点击；hover 时行底色变化、箭头右移。
3. **精选文章（02）**
   - 标题「从这几篇开始」；3 条大标题条目，带编辑标签、阅读时间与摘要。
4. **最近记录（03）**
   - 标题「最近记录」；最近 5 条，日期用等宽数字，右侧标签。
5. **收尾（04）**
   - 大字「保持联系」+ 一段话 + RSS / Telegram / GitHub 三个入口；关键词点亮动效。
6. **页脚**

### 3.3 文章页

- 顶部：面包屑（文章 / 分类 / 标题的路径感，但不显示完整长标题）。
- 文章头：分类标签、日期、阅读时间、字数、浏览量（有数据才显示）；h1；description；发丝线。
- 封面：有 `cover.image` 时显示 16:9 宽图；没有则不留空框。
- 正文区：桌面端左侧 3 列粘性目录，右侧 7 列正文；1024 以下目录移到正文前，以可折叠块呈现。
- 目录：只列 h2 / h3，当前章节高亮；不显示空目录。
- 正文排版：17px/1.85，段距 1.2em；h2 上方发丝线，h3 不加线；引用用左侧 3px 朱砂线；表格发丝线；图片直角描边、`loading="lazy"`、有尺寸时输出宽高。
- 代码块：顶部条显示语言 + 复制按钮；复制成功后就地反馈「已复制」；Chroma 颜色按新色板调整。
- 文章脚：标签胶囊、上一篇 / 下一篇两个大面板、复制链接 / Telegram / X 的分享行、回到顶部。
- GoatCounter 浏览量：更新 `goatcounter-views.js` 的选择器，改为写入新 meta 结构；接口失败时整块隐藏。

### 3.4 文章列表 / 归档

- 列表头：标题、描述、总篇数、RSS。
- 按年份分组：年份用大号等宽数字，左侧粘性；右侧是条目行。
- 行：日期、标题、分类、阅读时间、箭头；整行可点。
- 分页：上一页 / 下一页两个大按钮，中间显示页码。
- 归档页沿用同一套年份索引，但增加月份分组。

### 3.5 分类 / 标签

- 分类索引：2 列编号列表（移动端 1 列），每项显示编号、名称、篇数、最新一篇标题与日期。
- 长尾分类：胶囊列表，等宽计数。
- 不再使用随机色相；所有分类统一墨色 + 朱砂编号。
- 分类详情页：标题、篇数、RSS、描述；条目行与文章列表一致；底部「换个主题看看」胶囊。

### 3.6 项目

- 项目索引页：与首页项目区同一套行，但增加项目说明与结尾联系段。
- 项目详情页复用文章页版式；项目页通常是短文档，目录不显示。

### 3.7 搜索

- 保留现有 Fuse 搜索逻辑与所有元素 ID，只替换外观与结果行样式。
- 搜索框 56px 高，等宽 `/` 提示；分类筛选为胶囊；结果行显示标题、摘要高亮、分类、日期。
- 空状态显示最近搜索与按分类浏览；键盘 ↑ ↓ Enter 行为保持不变。

### 3.8 关于 / 404

- 关于页使用文章版式，但隐藏目录；开头用大字姓名与一句话定位。
- 404：超大 `404` 数字 + 一句话 + 返回首页 / 文章 / 搜索三个入口。

## 4. 技术方案

### 4.1 模板覆盖

在站点 `layouts/` 中新增或重写（不改主题文件）：

- `baseof.html`：新的 HTML 外壳，输出 `data-page`、`data-theme`、正文 id。
- `_partials/head.html`：保留主题的 SEO / OpenGraph / schema 调用，改为只打包「Chroma + 站点 CSS」，预加载字体，输出 `site.js`。
- `_partials/header.html`、`_partials/footer.html`：新导航与页脚。
- `_partials/post_meta.html`：等宽元信息行。
- `_partials/toc.html`、`_partials/breadcrumbs.html`、`_partials/cover.html`：新结构。
- `_partials/share.html`：复制链接 + Telegram + X。
- `index.html`、`_partials/home.html`、`_partials/home_projects.html`：新首页。
- `single.html`、`list.html`、`archives.html`、`taxonomy.html`、`term.html`、`projects.html`、`search.html`、`404.html`。
- `_markup/render-image.html`：输出 `decoding="async"`，资源可取得宽高时补 `width` / `height`。
- `_partials/extend_head.html`：保留现有统计与验证代码，补充字体 preload。

主题保留为底层：主题的 `opengraph.html`、`twitter_cards.html`、`schema_json.html` 继续调用；如果某个页面模板缺失，仍能回退到 PaperMod。

### 4.2 CSS 结构

`assets/css/extended/` 改为编号文件，保证打包顺序：

```
00-tokens.css      设计变量、明暗主题
10-base.css        reset、字体、排版、链接、焦点
20-shell.css       shell、导航、页脚、按钮、表单
30-home.css        首页
40-article.css     文章页、目录、代码、上下篇
50-index.css       列表、归档、分类、标签、项目
60-search.css      搜索页
70-404.css         404、关于页微调
80-motion.css      进入、hover、减弱动效
90-print.css       打印样式
```

`head.html` 只打包 Chroma 样式 + 上述站点 CSS，不再加载 PaperMod 的 `common/*.css`，避免两套布局规则互相覆盖。主题仍可回退模板，但页面样式由站点 CSS 完全负责。

### 4.3 JS

新增 `assets/js/site.js`（原生 JS，约 6–8KB）：

- 主题切换 + `localStorage` 记忆 + `meta[name=theme-color]` 同步。
- 移动端菜单：`aria-expanded`、Esc 关闭、焦点返回、滚动锁定。
- 目录当前项：`IntersectionObserver`，不做连续滚动动画。
- 代码块工具条：语言名 + 复制按钮。
- 首屏进入与收尾关键词点亮：只加 class，动画交给 CSS。
- 减弱动效：检测 `prefers-reduced-motion`，直接跳过。

保留并小改：

- `assets/js/fastsearch.js`：仅调整结果 DOM 的 class 与模板，不改搜索逻辑。
- `assets/js/goatcounter-views.js`：改为写入新的文章 meta 节点。

### 4.4 字体与资源

- 自托管 Space Grotesk Latin 子集（woff2，OFL 许可），放入 `static/fonts/`，附 `OFL.txt`。
- 只预加载 1 个字体文件；中文字体使用系统字体，零额外请求。
- 不引入 CDN、不引入图标库；图标使用内联 SVG（太阳/月亮、箭头、RSS、搜索、复制）。

### 4.5 配置调整

- `config.toml`：补充 `[params.assets] theme_color`、`favicon` 等已有路径；关闭不需要的分享平台或改由站点 partial 控制；保留 `ShowCodeCopyButtons` 等开关的语义。
- 不修改 `baseURL`、菜单 URL、内容 front matter、分页大小、统计代码与 CI 工作流。
- `.gitignore` 增加 `.taste-skill/`（本地截图与检查产物）。

## 5. 验收标准

### 5.1 构建与功能

- `hugo --minify` 零错误、零警告（除既有 Obsidian 模板忽略项）。
- 首页、文章页、列表、归档、分类、标签、项目、搜索、关于、404 全部生成。
- 搜索可用：输入、分类筛选、键盘上下、清空、最近搜索。
- RSS、`index.json`、OpenGraph、schema、GoatCounter、Cloudflare 脚本仍输出。
- 内部链接无 404：构建后用脚本遍历 `public/` 的所有站内链接。
- 不改动任何文章 URL；旧链接仍可访问。

### 5.2 版面与响应式

- 1440×900、1024×768、820×1180、768×1024、390×844、320 宽逐页检查。
- 无横向滚动、无重叠、无被固定栏遮挡的内容。
- 首屏主按钮在首屏内；每个区块标题与内容对齐到同一 shell。
- 中文正文行长不超过 36 个汉字；移动端单列。
- 所有可点击目标 ≥ 44px 高；相邻目标间距 ≥ 8px。

### 5.3 可访问性与动效

- 键盘：Tab 首先到 skip link；导航、菜单、主题切换、搜索、代码复制全部可操作。
- 焦点环在明暗主题下都清晰可见，不被 header 遮挡。
- 图片都有 alt；表单有可见标签；标题层级不跳级。
- `prefers-reduced-motion` 下无动画、无隐藏内容。
- 无滚动淡入、无视差、无倾斜。

### 5.4 性能

- 首屏 CSS + 字体 + JS 体积可控；字体只 1 个 woff2。
- 使用 skill 的 `perf.mjs` 检查首页与文章页，无 FAIL 行。
- 图片保持现有尺寸与懒加载；有尺寸信息时不产生明显 CLS。
- 不新增第三方请求。

### 5.5 与 design-taste-frontend skill 的关系

该 skill 的 gate / copy-lint / photo 规则面向企业营销站，个人博客没有对应的 page kind，也没有产品摄影。因此本计划：

- 采用它的版面、字体、动效、可访问性、性能与「不做模板感」的原则；
- 用 `shoot.mjs`、`perf.mjs` 做截图与性能检查；
- 不把 hero 摄影数量、产品图、copy-lint 英文套话规则作为阻塞项；
- 如需严格执行 gate，需要单独确认把它按 `service` 类型运行并逐条豁免，这会引入与博客无关的检查项。

## 6. 风险与取舍

| 风险 | 影响 | 处理 |
|---|---|---|
| 不再加载 PaperMod 公共 CSS | 若某模板回退到主题，会缺少样式 | 所有 HTML 页面模板都在站点内覆盖；验收时逐页检查 |
| 搜索 JS 与 DOM 强耦合 | 改 class 可能破坏搜索 | 保留所有 ID 与 `.search-result` 结构，只改外层 class；逐项回归 |
| GoatCounter 依赖 `.post-single .post-meta` | 浏览量可能不显示 | 同步修改 `goatcounter-views.js` 选择器并测试失败态 |
| Space Grotesk 下载失败 | 拉丁字体退化 | 回退到系统无衬线；页面不依赖字体加载 |
| 中文系统字体差异 | Windows 观感不同 | 使用多级 CJK 回退；在 1440 与 390 下检查字重与行高 |
| 双主题维护成本 | 两套颜色需分别校验 | token 化；对比度脚本 + 两套截图 |
| 大规模模板覆盖 | 与未来主题升级冲突 | 用户已确认不再更新主题；主题仅作回退与工具 partial |
