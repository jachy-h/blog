## 主要变更

### 外壳

- 新增 `layouts/baseof.html`，站点不再使用主题的 body / 页脚脚本结构。
- 新增站点级 `head.html`：只打包 Chroma + 站点 CSS，字体预加载，主题首绘前确定，SEO / OG / schema 仍调用主题 partial。
- 新增 `header.html`：居中导航、主题切换、全屏移动菜单；保留 skip link 与 `/` 搜索提示。
- 新增 `footer.html`：品牌说明、索引、订阅与联系、Hugo + PaperMod 署名。
- 删除旧的 `assets/css/extended/browse.css`、`goatcounter.css`、`projects.css`、`search.css`。
- 新增编号样式：`00-tokens`、`10-base`、`20-shell`、`30-home`、`40-article`、`50-index`、`60-search`、`70-404`、`80-motion`、`90-print`、`95-code`。

### 页面

- 首页：新的第一屏、INDEX 信息板、编号项目行、精选大标题行、最近记录、收尾大字与一次性关键词点亮。
- 文章页：面包屑、文章头、桌面粘性目录 / 移动端可折叠目录、正文样式、图片 `srcset`、代码语言与复制、标签、分享、源文件、上下篇。
- 列表 / 归档：年份 + 月份索引，年份标签桌面粘性；分页。
- 分类 / 标签：编号索引 + 长尾胶囊；移除随机色相，当前分类不再出现在“换个主题”里。
- 项目：首页与项目索引共用行组件；项目详情复用文章版式。
- 搜索：保留 Fuse 搜索逻辑与所有 ID，重做外观；去掉原生 `type=search` 清空钮与自动聚焦。
- 关于：静态文章版式，去掉重复的导语，保留正文。
- 404：大号 404 + 三个入口。

### 脚本

- 新增 `assets/js/site.js`：主题持久化与系统跟随、移动菜单（Esc、焦点、滚动锁）、目录当前项（同时更新桌面与移动副本）、代码复制、分享复制、收尾动效、全站 `/` 搜索入口。
- 修改 `goatcounter-views.js`：写入新的文章 meta 结构，接口失败时保持隐藏。
- 修改 `fastsearch.js`：移除自动聚焦，其余逻辑不变。

### 资源

- 自托管 `static/fonts/space-grotesk-latin.woff2`（22 KB）与 OFL 许可。
- `render-image.html` 为可处理图片生成 480 / 720 / 1080 / 1440 的 `srcset`，并输出宽高与懒加载。
- `.gitignore` 增加 `.taste-skill/` 与 `resources/_gen/`。

## 验收轮修复记录

以下问题在截图与浏览器检查中暴露并已修复：

1. 移动端目录把 TOC 原始 HTML 当作文本渲染（`replaceRE` 结果未标记 `safeHTML`）。
2. 桌面与移动两份目录共用 ID 映射，导致桌面当前项不再高亮；改为按 ID 保存链接数组。
3. 移动端表格撑破页面宽度；改为在 768 以下换行 + 内部横向滚动，并给第一列 `white-space: nowrap`。
4. 搜索页 Safari/Chrome 原生清空按钮与自定义清空按钮重复；输入改为 `type=text`，移除原生按钮。
5. 搜索页自动聚焦导致首屏跳过 skip link；移除自动聚焦，保留 `/` 与 `⌘K`。
6. 页头在 900px 以下把操作按钮挤到中间列；改为显式三列网格。
7. 中文文本使用 `ch` 作为最大宽度，实际按拉丁 0 的字宽计算，导致段落过早换行；统一改为 `em`。
8. 无 JS 时桌面出现重复导航；移动端静态导航缺少左右留白；已按断点处理。
9. 文章正文在 1100px 以下因自动外边距收缩到内容宽度；改为 `width: 100%` 后正常居中。
10. 首页 INDEX 面板与 H1 的顶部未对齐；改为顶部对齐。
11. 项目描述与页脚说明出现孤字换行；调整行宽并启用 `text-wrap: pretty`。
12. 分类详情页的“换个主题”把当前分类也列出来；改为大小写不敏感排除。
13. 文章 meta 的分类链接、页脚链接、标签、目录项等触控高度不足 44px；已补齐。
14. `srcset`：文章内可处理图片生成 480/720/1080/1440 变体；390 宽封面传输从 106.3 KiB 降至 8.7 KiB。
15. 文章 meta 的浏览量选择器迁移到新结构；实测显示「阅读 1 次」。
16. 关闭当前页面的 JS 时，主题切换、菜单按钮、复制按钮隐藏；移动端显示静态导航块。
