发布一个博客，总共分几步？

三步：创建博客站点，写博客，发出去。

- 博客站点是一个存在于本地的空壳
- 我们在站点里写文章
- 写完之后发布到网上

下面把这三步展开。

## 1. 【创建博客站点】：通过 Hugo 生成站点

Hugo 是一个静态网站生成器，用它来制作站点。

### 1.1 安装 Hugo

这里记录 Windows 和 macOS 下的安装步骤。

#### 1.1.1 Windows

打开命令行，输入：

```powershell
winget install Hugo.Hugo.Extended
```

（待验证）

#### 1.1.2 macOS

安装：`brew install hugo`
验证：`hugo version`

看到类似下面的版本输出，就表示安装成功：

```text
hugo v0.128.1+extended darwin/arm64 BuildDate=2024-07-02T06:46:41Z VendorInfo=brew
```

### 1.2 初始化站点

```bash
hugo new site test # 新建一个站点
cd test # 进入站点目录
git init # 初始化 git
git submodule add https://github.com/theNewDynamic/gohugo-theme-ananke.git themes/ananke # 添加主题
echo "theme = 'ananke'" >> hugo.toml # 配置主题
hugo server # 启动服务
```

启动后会输出一堆内容，关键是倒数第二行给出的地址，用浏览器打开即可：

```bash
# ... 略过其他输出
Running in Fast Render Mode. For full rebuilds on change: hugo server --disableFastRender
Web Server is available at http://localhost:1313/ (bind address 127.0.0.1)
Press Ctrl+C to stop
```

## 2. 【写博客】

接下来给博客加一些内容。

执行这行命令：

```bash
hugo new content content/posts/my-first-post.md
```

Hugo 会在 `content/posts` 下创建这个文件。打开并编辑 `my-first-post.md`：

```markdown
+++
title = 'My First Post'
date = 2024-07-05T09:20:35+08:00
draft = true
+++
```

`draft = true` 表示这还是一篇草稿。写完后改成 `draft = false`，再执行 `hugo server`，就能看到文章了。

可以先随便加点内容试试。

## 3. 通过 GitHub Pages 发布站点

1. 在 GitHub 新建仓库，把本地站点推送到 `main` 分支。
2. 进入仓库的 Settings → Pages，把 Build and deployment 的 Source 设为 GitHub Actions。
3. 在仓库中添加 `.github/workflows/pages.yml`，由 Actions 安装 Hugo、执行构建并部署。本博客的工作流大致做四件事：
   - 安装指定版本的 Hugo extended；
   - checkout 仓库并拉取主题子模块；
   - 执行 `hugo --minify`，生成 `public`；
   - 上传产物并部署到 GitHub Pages。

推送后，可以在仓库的 Actions 页面查看构建和部署结果。

## 4. 映射到自己的域名

### 4.1 搞个域名

在域名服务商处购买域名。

### 4.2 配置 HTTPS

1. 在仓库 Settings → Pages 的 Custom domain 中填写域名；
2. 在 DNS 服务商处添加记录，`www` 或子域名指向 `<用户名>.github.io`；
3. 保存后等待 GitHub 完成证书签发，再开启 Enforce HTTPS。

## FAQ

### 1. 启动后是空白页面，并报错如下

```text
WARN 2024/07/04 21:05:13 found no layout file for "HTML" for kind "page": You should create a template file which matches Hugo Layouts Lookup Rules for this combination.
```

这通常是因为主题加载失败。通过 `submodule` 加载的主题没有拉取下来，重新初始化即可：

```bash
git submodule update --init --recursive
```

### 2. 新设备上修改或新增文件，`hugo serve` 中没有变化

根本原因：`themes/PaperMod` 目录是空的（git submodule 未初始化），Hugo 找不到布局模板文件。
解决方案：初始化主题。

```bash
git submodule update --init --recursive
```
