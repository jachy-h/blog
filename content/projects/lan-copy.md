零依赖的局域网文件与文本快传工具。

## 解决的问题

设备之间临时传输文件或文本，是一个很小却反复出现的需求。lan-copy 聚焦局域网内的快传，采用 Go 实现，保持工具体积与依赖简单。

## 使用入口

[前往 GitHub 查看源码与使用说明](https://github.com/jachy-h/lan-copy)

安装方式、命令参数和支持平台，请以仓库 README 为准。

## 适用范围

适合局域网设备之间临时传递文件或文本。使用前需要确认设备间的网络连通性；跨公网访问和长期存储不属于这里描述的使用场景。
